# 授業準備の動画再生と当月録画取得

2026-11-06。本人が再開・修正・検証・本番反映を指定した範囲。

- `lesson_prep.html` の完成確認表示を「動画を見る」リンクに変更。同一授業の完成確認済みURLのみ表示し、新しいタブで開く。訂正URL・非公開判定・コピー・公開設定を共通の既存照合結果から引き継ぐ。
- 独立公開の既定月は日本時間の当月。取得前に公開用リポジトリをfetchし、`origin/main:schedule_YYYY-MM.json` を正本として読む。ローカルの古い月や `schedule_latest.json` へ切り替えない。原本欠落・空・混在月はエラーにする。
- `make_recording_json(..., schedule=...)` で正本予定を渡す。既存の引数なしの呼出しを維持。独立取得でExcel日誌を開かない。
- PCの既存cmdは、LOCALAPPDATAの公開用リポジトリ内にある検証済みコードを起動する。既存 `.env`・会議IDは `--config-dir` で読み、認証情報を複製しない。既存ログ・エラー表示・非表示起動を維持。タスク時刻を変更・追加しない。
- `--dry-run` はfetchと取得・照合までとし、ファイル出力・コミット・push・rebaseへ進まない。明示した過去月の公開は当月latestを置き換えない。
