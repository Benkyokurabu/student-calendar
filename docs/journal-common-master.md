# 授業日誌の通常用共通マスター

通常用（S/A/B・補講）の正式なマスターは、OneDriveの
`デスクトップ/【完成版】授業日誌システム/TEMPLATE_MAIN_COMMON.xlsx`。
編集用ファイルと正式なマスターを分け、編集中の保存だけでは本番へ適用しない。
X用は従来の別レイアウトを使う。

正式登録後は、クラウドの日誌更新が同じOneDriveファイルを直接取得する。
`create_month_sheet(..., template_path=...)` は、新しい月を作るときに
通常用共通マスターを直接コピーする。各年ファイルの内部テンプレートの
古いレイアウトに引き戻されない。既存月は作り直さず、保存済みの本文・
回数・日付・書式を保持する。正式なマスターが未登録なら従来の生成経路を保つ。

マスターにはコピー元の校舎・学年・科目・回数が残っていてよい。
生成時に全21枠の校舎・学年・科目を対象に合わせ、年間授業回数を前月の
記録と繰り越し扱いから設定する。コピー元の固定回数や「特」を引き継がず、
特別授業の表示は実際のスケジュールから設定する。「何月何週」の値や数式は
空欄にし、既存のカレンダー出力と繰り越し計算の情報は非表示領域に保持する。

コピー時は列幅・行高・セル書式・結合・プルダウンに加え、印刷範囲・
用紙設定・ヘッダー・フッター・条件付き書式・注記も保持する。
共通マスターに月ごとの記録シートが混入していたり、必須のプルダウンが
欠けていたりする場合は、新しい月を追加せずに停止する。

正式登録するときは、保存された編集用ファイルを確認し、OneDriveの
既存マスターがあれば `cloud_backup.py` でルートの `backup` へ退避してから
正式名へ登録する。アップロード後はクラウドから再取得して内容を照合する。
編集途中のファイルや、以前のPCにしかない編集を推測して登録しない。

関連試験:
`python -m unittest discover -s scripts -p test_journal_common_master.py -v`

## 特別授業の列の色

「特」がある列では、その特別授業の入力欄を白く保ち、授業がない他クラスの
入力欄は右端の未使用枠と同じ灰色で塗る。色の範囲と色値は既存の
`gray_out_block()` を共用する。後続の色修復が空欄を白へ戻さないよう、
`restore_unused_slot_colors()` をクラウド・手動実行の両方で使う。
この処理は塗りつぶしだけを更新し、本文・日付・回数・数式を変更しない。
別クラスに実際の日付がある場合は、その記録を使える状態に保つ。

関連試験:
`python -m unittest discover -s scripts -p test_journal_special_colors.py -v`
