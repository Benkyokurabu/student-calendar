# カレンダーの読み込み待機への対応

2026年10月23日。勉たんの遅刻・欠席と同時に学生カレンダーでも不具合があるという申告を受けて確認した。

カレンダーは勉たんの授業APIと録画公開設定APIを呼び、その先は同じSupabase DBを使っている。授業APIに接続できない場合は対象月の保存済みJSONへ切り替わるが、録画公開設定の応答を待つ間、授業の画面描画まで待っていた。公開HTMLと接続先のコード、10月の保存済み397件の取得を確認した。

今回の修正では、授業データを先に表示し、指導内容・宿題・録画は後から更新する。通信はJSON本文の受信も含めて8秒を上限とする。録画の公開状態が不明な間は録画リンクを表示しない。取得失敗を「宿題なし」や「公開済み」と扱わず、表示できている範囲と未取得の情報を説明する。30秒ごとの再確認で回復したら、選択中の校舎・クラス・日付を保って表示へ反映する。別の月へ移動した後に前の月の通信が完了しても、その結果で現在の表示を置き換えない。

保存先サービス内部で遅延している理由や、無料枠・猶予期間との関係は未確定。今回の変更は画面全体が待ち続ける問題への対処であり、保存先サービス自体を復旧したことを意味しない。

通常・無応答・JSON本文の無応答・HTTP失敗、従来の録画優先順位と公開制限、選択状態、授業ソースの検証を実施する。390px/1280pxでは共通APIの無応答を再現し、保存済み授業の表示、公開状態が不明な録画の抑止、回復後のリンク表示と選択維持を確認する。
